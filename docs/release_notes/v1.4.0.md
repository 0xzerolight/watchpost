### Added

- **Repository switcher and previous/next links (repo page).**

- **Event impact lines (repo page, Events).** Views per day and the star change before and after
  each event.

- **Views change against the previous period (Analytics).**

- **Share bars behind traffic-source names (repo page).**

- **Sync failures on Repositories and Analytics.**

- **Period carried in links between pages.** Picking 30 days on Analytics keeps it when you open a
  repo.

- **A notice when JavaScript is off.**

### Changed

- **Traffic sources as two side-by-side tables (repo page).** Ten rows each with Show all for the
  rest, labelled as all-time.

- **A shorter events list (repo page).** One line per event, with the newest ten shown and older
  ones behind "Show N older events".

- **KPI tile captions (repo page).** Each tile says the span its figure covers.

- **One chart tooltip for figures and events.**

- **One accent colour for every chart series.**

- **Compact event form with confirmations (repo page).**

- **Leaderboard columns labelled by period (Analytics).**

- **Recent changes grouped by day (Analytics).**

- **Dashboard cards (Repositories).** Even rows, and the whole card opens the repo.

- **First-run guidance from setup to the first sync.**

- **Repository picker order and layout (Settings).** Tracked repos first, with Save selection
  under the table.

- **Settings and setup layout and wording.**

- **Current section marked in the nav.**

- **One type scale, section rhythm and table style.**

### Fixed

- **Pages no longer scroll sideways on a phone.**

- **The sync panel no longer reports a skipped or rate-limited cycle as a success (Settings).**

- **Portfolio badges no longer count a newly tracked repo as growth (Analytics).**

- **Release downloads count a renamed asset once.**

- **A rejected setup token no longer nests a second page inside the form.**

- **Unknown addresses and malformed ids show the styled Not found page.**

- **Muted text, deltas and borders meet AA contrast in both themes.**

- **Keyboard focus and chip state show without colour or hover.**

- **Swapped confirmations are announced once.** Screen readers hear each add, save or delete
  confirmation one time.
